# 01 · Curriculum map — তৃতীয় শ্রেণির গণিত খেলাঘর

Each row is one **topic** (পাঠ) in the app, in book order. Columns: book pages, the toy (codes T1–T15 and the other toys are in the shared [packages & kits](../../../plan/04-packages-and-kits.md#math-kits-and-their-toys)), the Explore hook/interaction, what Practice generates, and an optional mini-game. **MVP** marks the first release (Phase 1). Topics **6.1, 6.2 and 6.5** are the **Phase 0 slice**.
Full source notes per chapter: `../references/chapters/`.

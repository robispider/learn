# অধ্যায় ১২ — জ্যামিতি (Geometry)

- **Book pages:** 133–148 · **PDF pages:** 139–154
- **Scope:** point, line, flat & curved surfaces → angles (right, acute, obtuse, straight) by paper folding → quadrilaterals (আয়ত, বর্গ) → geometric patterns.

## Interactive / fun ideas
1. **Connect-the-dots sky** — tap stars to join them into constellations (points → lines).
2. **Surface Sorter** — 3-D objects rotate; drag into সমতল / বক্রতল / উভয়; touch a face to feel "flat/curved" highlight.
3. **Angle Tester** — fold a virtual paper twice to make a right-angle corner; drag it onto any angle to classify (fits / gap / overlap) → acute/right/obtuse.
4. **Angle Maker (sticks / clock hands)** — rotate one stick; label changes live; sound pitch rises with angle.
5. **Angle Hunt** — find & tap angles in a village scene (house roof, kite, scissors).
6. **Shape Lab on dot paper** — draw quads by tapping dots; app names it (চতুর্ভুজ / আয়ত / বর্গ) and explains why; "make a square" challenges.
7. **Robot walk** — program a robot with "forward / turn right-angle" around a rectangle (early coding + angles).
8. **Pattern Studio** — continue / fix / create patterns with shapes & colours; nested-square Baishakhi decoration maker (export as image).

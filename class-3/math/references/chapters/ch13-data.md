## Vocabulary
উপাত্ত (data), সংগ্রহ (collect), বিন্যস্তকরণ (organise), সারণি (table), ট্যালি চিহ্ন (tally mark), চিত্রলেখ (pictograph), প্রতীক (symbol), "প্রতিটি ● = ১০ জন" (key/scale), সবচেয়ে বেশি / কম, মোট.

## Book visuals worth reusing
- Shishu park scene (rides) — great for a counting game.
- Tally mark with pencil.
- Pictographs with fruit icons, circles, half circles, stars, leaves, vehicles, books.

## Interactive / fun ideas
1. **Park Counter** — children appear on rides in an animated park; tap to add a tally per child; every 5th mark slashes across with a "swish"; table fills automatically.
2. **Colour Shout** — audio calls colours randomly (Bangla voice); kids tally; compare at end (listening + tallying).
3. **Pictograph Builder** — drag icons into rows; choose key (1, 2, 5, 10); app shows halves; switch horizontal ↔ vertical; compare with a bar.
4. **Survey My Class** — teacher-mode: collect class favourites (fish, fruit, colour) live on one device; auto pictograph; print.
5. **Data Detective** — read a pictograph and answer questions with partial symbols; find the scale from one known value (vehicle puzzle).
6. **Tree census at home** — offline project template (print table → enter → pictograph).
